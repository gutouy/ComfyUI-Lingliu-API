# WAN3 低价 V15 示例

将 assets 目录内的 20 个测试素材复制到 ComfyUI/input，然后加载对应工作流 JSON。
01 为单图参考，02 为 1 图 + 1 视频 + 1 音频，03 为 10 图 + 5 视频 + 5 音频。
示例不包含密钥；在灵流 API 设置节点或 WAN 节点中填写自己的密钥。
运行生成节点会真实调用平台并按当前价格扣费。导入和查看工作流不调用 API。
示例默认 1080p、2 秒，因为该变体已有平台满载成功记录。其他变体见主 README 的验证范围。
测试素材为本地合成的简单图形、移动色块和低音量正弦波，用于检查连接和顺序。
